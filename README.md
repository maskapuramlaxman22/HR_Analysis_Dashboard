# 👥 HR Analytics Dashboard

## 📊 Project Overview

This project is an interactive **HR Analytics Dashboard** created using Microsoft Excel.

The dashboard provides insights into employee demographics, workforce distribution, employee attrition, salary patterns, and hiring trends.

The goal of this project is to transform HR data into meaningful visual insights that can help understand workforce performance and support data-driven HR decisions.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Design

## 📈 Dashboard Analysis

### 1. Employee by Department
Shows the distribution of employees across different departments.

### 2. Attrition by Department
Analyzes employee attrition across departments to identify areas with higher employee turnover.

### 3. Attrition by Job Role
Shows the number of employees leaving the organization across different job roles.

### 4. Employee by Age
Displays the distribution of employees across different age groups.

### 5. Average Salary by Department
Compares the average salary across different departments.

### 6. Hiring Trend by Year
Shows how employee hiring has changed over the years.
